# GPT-6.1 Sol Codex Model Router v1.1.0

GPT-6.1 Sol replaces GPT-6 Sol for everyday work. GPT-6 Luna remains the narrow-task option; GPT-6 Astra remains available for demanding coordination, long-context dependencies and costly hidden failures. Both allowance profiles retain the language-specific confirmation workflow.

The US$20 profile now maps Astra Low/Medium to GPT-6.1 Sol XHigh, and Astra High or above to Astra Low. Apply the mapping once. These are quota preferences, not measured model equivalences.

The repository is now `alanliuc-a11y/codex-model-router-gpt-6-1`. Skill names remain `model-router` and `model-router-20`. Fresh installs, ZIP downloads and upgrades are documented in the [English guide](../../README.md) and [Chinese guide](../../README.zh-CN.md). Back up existing installations outside the skills directory before reinstalling.

Historical screenshots and release notes describe earlier model generations. GPT-6 Sol's benchmark results are not GPT-6.1 Sol results; no comparable new-model effort table was verified for this release.

Validation covers both skill structures, current model/effort availability, global-rule synchronization and preserved user instructions. Manual routing cases are included for user testing; they are not empirical benchmark results.
