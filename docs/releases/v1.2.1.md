# Model Router v1.2.1 — reliable update checks without credentials

Includes the update reminders and backup-first same-profile upgrader introduced in v1.2.0.

Real-client validation found anonymous GitHub API rate limiting. This patch falls back to GitHub's canonical latest-release link on 403/429, accepting only stable numeric tags from the managed repository. It never reads user credentials, changes the model catalog or bypasses hook trust.

Fresh install, ZIP download and existing-install upgrade prompts now target v1.2.1. Older installs affected by rate limiting can bootstrap with the [README upgrade instructions](../../README.md). Script tests include the fallback and reject redirected foreign URLs; client hook acceptance still requires the user's review.
