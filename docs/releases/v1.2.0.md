# Model Router v1.2.0 — update reminders and safe upgrades

Historical release. Use [v1.2.1](v1.2.1.md) for the anonymous rate-limit fix and current installation instructions.

Model choices remain GPT-6 Luna, GPT-6.1 Sol and GPT-6 Astra. Both allowance profiles retain their existing reasoning rubric.

New: verified update notices below recommendations; cache-only foreground hooks and daily asynchronous public GitHub release checks. No newer version means the usual three-line response. A first check may surface a notice only on a later task.

Send `update router` to explicitly authorize a same-profile upgrade, or `check router update` for a manual check. The updater verifies staged package files, backs up the install and configuration outside skill discovery, and rolls back caught installation failures. An update command does not execute a pending task.

Python 3.10+, supported Codex hooks and explicit hook trust are required for reminders. Existing installations must upgrade once. No silent installation, one-click installer link or OS push notification. Configuration generation alone is not proof the desktop client ran a hook. See the [English guide](../../README.md) and [acceptance steps](../update-testing.md).

## 中文说明

新增模型推荐下方的更新提醒。没有新版时仍保持三行；联网检查每天最多一次且后台运行，首次提醒可能出现在下一项任务。

单独输入「更新路由器」才会升级；输入「检查路由器更新」可以立即检查。升级保留原档位、校验下载、备份旧技能和配置，安装过程中可捕获的失败会恢复旧版。更新命令不会执行待确认任务。

首次启用需审核并信任检查脚本，老用户必须先升级一次。不能把配置写入成功当作客户端已经运行成功。见[中文安装说明](../../README.zh-CN.md)和[测试步骤](../update-testing.zh-CN.md)。
