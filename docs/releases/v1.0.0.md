# Model Router v1.0.0 — historical release

For current GPT-6.1 Sol support, installation and upgrade instructions, use [the current README](../../README.md) and [v1.1.0 notes](v1.1.0.md). The model names below describe the original release.

First stable public release of the Codex Model Router skill.

## Highlights

- Routes Codex tasks across GPT-5.6 Luna, Terra, Sol, and GPT-6 Astra.
- Keeps model choice and reasoning effort separate.
- Supports a one-time global-routing setup, so future tasks can be written normally without adding `$model-router` each time.
- Uses a deliberate two-step flow: choose the recommendation in Codex, then confirm the task with `go` (English) or `执行` (Chinese).
- Includes English and Chinese documentation, tested setup scripts, and authentic workflow captures.

## Important boundaries

- Model Router recommends; it does not automatically switch the active model of an already-running task.
- It does not change Codex speed settings.
- It does not promise a fixed token-saving percentage.

See the README for installation and usage instructions.
