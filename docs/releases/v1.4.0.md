# v1.4.0 — GPT-6.2 support, GPT-6.1 Sol value, ChatGPT Plus / Pro

The router now evaluates GPT-6 Luna, GPT-6.1 Terra, GPT-6.1 Sol, GPT-6.2 Sol and GPT-6.2 Astra. Newer is not automatically more cost-effective.

Installation choices use the official ChatGPT Plus and ChatGPT Pro names, not dollar bands. Plus retains a proven 6.1 Sol baseline. Pro considers 6.2 Sol first but preserves 6.1 preferences, context/billing advantages and demonstrated value. Both keep task-quality gates and use explicit supported user choices.

The official baseline credit rates for both Sol versions match; the pricing page expressly exempts 6.1 subscription usage from long-context surcharge. Neither fact proves a universal cheaper-per-task result. The bundled dated pricing policy distinguishes allowance, purchased credits and API billing, and compares effort, context/caching, quality and rework without changing speed settings.

The Plus Astra-conservation mapping is applied once to the selected value-Sol (normally 6.1) or Astra 6.2 Low. Pro retains the base recommendation. A reduced effort is not equal quality or guaranteed savings.

Repository and internal skill/path identifiers stay stable for old updaters. Fresh install, ZIP download and explicit-upgrade instructions all target v1.4.0. A release request does not upgrade the real local installation; validation uses isolated homes. Hook trust remains user-controlled.

Sources checked 2026-11-19: [official credit/allowance pricing](https://learn.chatgpt.com/docs/pricing), [6.2 launch](https://learn.chatgpt.com/docs/whats-new/gpt-62-astra-sol), [model/context guidance](https://learn.chatgpt.com/docs/models).
