# v1.3.0 — GPT-6.1 Terra + Sol Codex Model Router

GPT-6.1 Terra joins GPT-6 Luna, GPT-6.1 Sol and GPT-6 Astra. Use Terra for bounded writing from supplied material, chart/screen interpretation, defined computer-use outcomes and scoped known-cause code fixes with concrete checks.

Terra is an added option, not a blanket Sol replacement. Luna remains for mechanical work; Sol handles broader work and coupled or unknown bugs; Astra remains for demanding coordination and costly hidden failures. Both allowance profiles use the same gates. The US$20 Astra Low/Medium → Sol XHigh and Astra High+ → Astra Low rules are unchanged and applied once; they do not alter Terra routes.

The reviewed Codex catalog exposes Low through Max for Terra and a client-specific Ultra option. Its API None option is not available in that local Codex catalog. Terra needs CLI 0.159.0+ and actual account/client availability. No automatic model switch, speed adjustment, fixed savings or measured Terra/Sol equivalence is claimed.

The repository address and skill names stay unchanged. See the [English guide](../../README.md) for v1.3.0 installation, ZIP downloads and same-profile upgrades. Existing v1.2.1 users can use `update router`; the updater preserves reminder settings and unrelated rules. Hook trust remains user-controlled. [Manual routing acceptance](../routing-cases.md)

Official sources reviewed 2026-10-28: [Terra specifications](https://developers.openai.com/api/docs/models/gpt-6.1-terra), [model selection](https://learn.chatgpt.com/docs/model-selection), [Codex availability](https://learn.chatgpt.com/docs/models).

## 中文说明

新增 GPT-6.1 Terra，适用于资料和验收标准明确的写作、图表与界面解读、目标明确的软件操作，以及小范围、原因已知且可核对的代码修复。并非把所有 Sol 任务降到 Terra。

简单机械任务仍用 Luna；复杂或功能联动任务保留 Sol；困难整合及隐蔽错误风险保留 Astra。两档共用新规则，20 美金档原有的 Astra 转换策略保持不变，不转换 Terra。
