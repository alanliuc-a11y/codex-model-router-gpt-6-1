# v1.5.0 — Four subscription strategies and native install selection

Install requests now ask once using native clickable Plus / Pro 100 / Pro 200 / Pro 500 choices when the host supports four options. No typed plan name, default selection, simulated Markdown buttons or timeout-as-consent. Unsupported clients pause. A plan supplied explicitly skips the question.

Plus keeps the existing conservation mapping; Pro 100 favors a proven 6.1 Sol baseline; Pro 200 balances 6.2 Sol and Astra integration; Pro 500 prioritizes first-pass quality for difficult integrations. Routine-task gates and fixed speed settings remain. These are project strategies, not official quota guarantees.

Three new Pro packages persist the selected plan through manifest identity and global rules. Old Plus and generic Pro identities remain valid for same-profile upgrades. Legacy generic Pro never implies a numbered Pro tier. Only one router should be active.

Reviewed official model catalog/changelog and Pro tiers on 2026-11-24. Latest verified model family remains GPT-6.2 Sol/Astra; no unverified successor is added. Retain 6.1 Sol as an active value choice. No automatic upgrade of the real local install.

Sources: [models](https://learn.chatgpt.com/docs/models), [changelog](https://learn.chatgpt.com/docs/changelog), [Pro tiers](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers).

四档分别采取节省优先、性价比优先、均衡、困难任务质量优先的项目策略；保留 6.1 Sol，不改速度，不保证固定节省比例。通过独立包保存选择，升级不换档；旧通用 Pro 保留兼容，不猜具体档位。本机不会随仓库发布自动升级。
