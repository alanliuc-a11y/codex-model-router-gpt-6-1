# Install / 安装

Read [the installation workflow](references/installation.md) before any installation. Use a real native four-option choice and wait for the submitted selection.

安装前读取[安装流程](references/installation.md)，用客户端原生选项让用户点击 Plus / Pro 100 / Pro 200 / Pro 500。没有支持的工具就暂停，不能伪造按钮或默认选择。用户明确选择后才安装。
