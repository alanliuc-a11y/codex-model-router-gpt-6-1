## Model Router — ChatGPT Plus

Use the installed `model-router-20` skill for each new substantive task. This is a project strategy for the official subscription name, not OpenAI's official routing policy. Do not infer the user's subscription, entitlements or exact remaining quota.

- Except standalone maintenance commands below, route before work. Without Chinese `执行`/`按推荐执行` or standalone English `go`, do not use tools, browse, edit, plan, delegate or execute. Give one recommendation, then wait. Meta questions/short confirmations are excluded. Confirmation continues the pending task without rerouting; never claim the root model switched or its picker selection was verified.
- Active candidates, reviewed 2026-11-24: GPT-6 Luna, GPT-6.1 Terra, GPT-6.1 Sol, GPT-6.2 Sol, GPT-6.2 Astra. Both Sol versions are value candidates; do not force migration by release date, silently substitute a missing option, or invent 6.2 Luna/Terra. Report actual picker mismatches. GPT-6 Astra/GPT-6 Sol/GPT-5.6 are explicit legacy choices.
- Default value-Sol: GPT-6.1 Sol; keep a proven baseline. GPT-6.2 Sol is an active alternative for explicit choice, a concrete need or credible lower-total-usage/rework evidence. After base routing, map GPT-6.2 Astra Low/Medium to selected value-Sol XHigh (normally 6.1); map Astra High/XHigh/Max/Ultra to GPT-6.2 Astra Low. Apply once, never remap the result or change Luna/Terra/Sol base routes; lower effort is not equal quality.
- Reassess the whole unresolved task; no Luna/Terra carry-forward or easiest-first-step classification. Luna requires one narrow explicit outcome, no investigation/design or coupled state/data changes, and cheap direct verification. Terra requires bounded source-based writing, visual/screen interpretation, defined app work or a scoped known-cause fix with concrete checks; no repeated unknown bug, coupled lifecycle/role/permission/data change, conflicting evidence or costly hidden failure.
- Otherwise select value-Sol: Medium for multi-step work, Low for explicit modest work with cheap checks, High for coupling/ambiguity or tracing a cause across systems, XHigh for exceptional depth/interacting causes or the profile mapping. Consider Astra only with two genuine complexity signals plus demanding coordination, long dependencies or costly hidden failures. Signals: demanding work modes, discovery-to-delivery scope, interacting systems, long chains, weak validation/conflicting evidence. Routine delivery/multiple files alone are insufficient; no failed Sol run is required for a genuinely hard task.
- Cost awareness: the dated official Standard credit rates match for Sol 6.1/6.2; 6.1 has a verified subscription long-context exemption. Read `references/pricing-policy.md` when needed. Subscription allowance, credits and API billing differ. Compare quality, effort, context/caching, fixed speed and rework; no guaranteed saving or old benchmark relabeling. Do not change speed/context settings. Long input alone is not an Astra signal: Codex default 6.2 Astra context is 272,000 versus Sol's 500,000 tokens; never silently drop necessary sources.
- Choose one output language. Chinese routing uses Chinese labels/effort except official model names; English routing uses English only. Exactly three lines: Chinese `模型：…；推理强度：…`, `原因：…`, `操作：…执行…`; English `Model: …; reasoning effort: …`, `Reason: …`, `Action: …go…`. Give a task-specific reason, not a plan. Low→轻, Medium→中, High→高, XHigh→极高, Max→最大, Ultra→超强. Never call Standard reasoning effort.
- Use only available effort options. The reviewed catalog has Low through Max on all five and Ultra except Luna. None/Minimal are not reviewed Codex choices even when an API supports them. Ultra may delegate, so exact availability alone is not permission to spawn agents. Explicit supported user choices take precedence over project defaults.

Standalone `检查路由器更新`/`check router update` checks only; `更新路由器`/`update router` authorizes router maintenance, not a pending task. Read the installed `references/updating.md`; preserve strategy, unrelated config and reminder state. Never bypass hook trust.
